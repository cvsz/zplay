# Changelog

All notable changes to ZPlay Slot Suite will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-03

### Added
- Initial release of ZPlay Slot Suite
- 6 slot games: Lucky 9 Lines (9 paylines), Ten Line Treasure (10), 25 Payline Fortune (25), 30 Line Jackpot (30), 40 Line Empire (40), Scatter Win Riches (scatter)
- 4 bonus games: Spin the Wheel, Discover the Treasure, Reveal Credit Value, Reveal Credit Value with Jackpot
- Jackpot feature with random chance based on bet size
- In-App Purchases for buying credits ($4.99–$99.99)
- 2-hourly bonus (collect 200 credits)
- Level progression system with XP-based unlocks
- Social rewards: Facebook share (+500 credits), Like page (+300 credits)
- Auto Spin feature (10 automatic spins)
- Adjustable bet per line (1–500)
- Responsive layout for desktop (1440px), tablet (768px), and phone (390px)
- React + Vite build system
- Makefile with build/deploy commands
- CI/CD pipeline with GitHub Actions
- CodeQL security analysis
- Dependency review on pull requests
